# 用户端 UI/UX 品鉴报告（simple-theme）

日期：2026-11-27  
范围：登录后用户能看到的全部页面（含公共查询/模型广场/支付结果等入口），管理员后台保持原样，不在本次评审范围。

## 总评

这一版把「控制台」从传统后台的侧栏+表格+深蓝灰，收敛成了一套面向 C 端的极简控制台：
纯黑/纯白画布、单一荧光绿强调、Space Grotesk 大字排版、细线卡片与大量留白。登录后不再像进入管理系统，而像进入一个消费级 AI 产品。

本次评审实际走过 27 条路由，覆盖 1440 / 1024 / 768 / 390 / 320 五档宽度，以及暗色/亮色两套主题。所有页面均无横向溢出；移动端使用底部 Tab 和单列卡片/行式列表，桌面端使用顶部主导航。

## 导航与外壳

- 桌面：品牌 → 概览 / 通行证 / 用量 / 套餐 / 充值 / 模型，右侧余额、语言、主题、账户菜单。
- 平板：视频宽度落在 700–1023 时，底部 Tab 变成居中悬浮胶囊，不遮挡左右内容。
- 手机：固定底部 Tab（概览 / 通行证 / 用量 / 充值 / 我的），右上角账户菜单与菜单抽屉承接其余页面。
- 账户菜单：账户设置、我的订单、兑换额度、邀请返利、MCP、管理后台（仅管理员）、退出登录。
- 品牌 logo 在登录后回到概览，不再把用户带回营销首页。

## 逐页品鉴

### 概览 /dashboard
第一眼是「今日概览」和余额大事记，信息顺序是：余额 → 今日调用/Token/累计消耗 → 更多细节 → 平台拆分 → 近 7 天趋势 → 模型用量 → 最近调用 + 快速开始。
移动端把余额卡放到首屏、指标两列、列表纵向排列，重点没有丢。余额卡的轨道线稿只在桌面出现，避免手机首屏拥挤。
建议：如果真实数据只有 1 天，趋势图会出现单点；已处理为显示数据点，后续数据多了自然成为完整曲线。

### 通行证 /keys
桌面两列卡片（4 张正好 2×2，奇数时最后一张整行），每张卡的信息层级是名称 → Key → 今日消耗/并发/到期/创建 → 额度条 → 操作。
移动端卡片单列，操作行可换行；底部 Tab 的「通行证」高亮。旧蓝灰分页条已被替换为细线 + 荧光当前页。

### 用量 /usage
顶部先给「这个区间，你花了多少」的总额与请求/Token 摘要，然后按每日趋势、模型分布、分组分布、端点分布展开，最后才是调用明细。
筛选默认折叠，减少第一屏噪音；桌面 1200px 以上展开四列，移动端分页按钮改成 40px 触控高度。

### 计费链路 /purchase /subscriptions /orders /payment/*
空态都有明确下一步：没有支付渠道时解释「站点还没开通收款渠道」并给出刷新/看套餐；没有订单时给「去充值」；二维码过期有兜底，不再出现空白倒计时页面。
订阅页保留一张价格卡空态；支付结果、Stripe、Airwallex、二维码、Stripe 弹窗共用同一套卡片与按钮语言。

### 账户 /profile
按 01 身份 / 02 安全 / 03 余额提醒编号分段，不再是卡片堆叠。身份卡展示余额、并发、注册时间；安全区密码表单与 2FA/Passkey 并排，右列不再出现空洞。
移动端全部单列，操作按钮 44px 以上。

### 兑换 /redeem 与 邀请 /affiliate
兑换页只做一件事：输入兑换码 → 看余额与记录；邀请页把四个数字收进一条数据面板，邀请码/链接复制反馈明确。

### 模型广场 /model-plaza
标题、三项统计、筛选胶囊、按分组陈列的模型卡。移动端筛选 chip 自动换行，不截断；空态会告诉用户「暂时没有匹配的模型」并给清除筛选。

### 渠道 /monitor
渠道监控以「上游健康」叙事：状态点、最近检测时间、平均延迟，然后是渠道行；V1 与 V2 共用设计令牌，V2 的矩阵/趋势也改成黑底 + 品牌色。

### 批量生图 /batch-image
筛选区重排为「搜索 + 三个筛选」一行，右侧重置/刷新/使用说明/创建；费用列不再被裁切；移动端操作按钮三列 + 主按钮整行，表格走卡片模式。

### 设置 /settings/mcp
未启用时不是抛英文技术错误，而是「MCP 还没开启」+ 管理员配置说明；已授权列表空态用细线虚线框说明「暂无授权应用」。

### 公共页
登录/注册保持单卡片居中；忘记密码/重置密码/邮箱验证改为紧凑高度，不再留 450px 空白；Key 用量查询、法务、404、OAuth 回调、MCP 授权都统一到同一套外壳。

## 跨终端与主题

- 1440：主导航完整展开，内容最大宽度 1200，卡片两列/三列按页面语义决定。
- 1024：导航仍完整；内容按 4 列指标或 2 列卡片收缩。
- 768：底部 Tab 悬浮居中，桌面侧栏不存在。
- 390 / 320：底部 Tab 固定，账户菜单/页面抽屉可打开全部页面；所有主操作至少 44px，无横向滚动。
- 暗色是主形态（黑画布 + 荧光绿），亮色是白画布 + 墨色文字 + 荧光绿强调，两套都用同一组 --st-* token。
